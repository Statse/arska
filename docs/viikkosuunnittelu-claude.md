# Viikkosuunnittelu käyttöön Claudessa

Tarvitset Claude-tilin. Tee käyttöönotto tietokoneen selaimessa.

1. [Lataa viikkosuunnitteluskilli](https://github.com/Statse/arska/raw/refs/heads/master/downloads/viikkosuunnittelu.zip). Säilytä ZIP-tiedosto sellaisenaan, älä pura sitä.
2. Avaa [Claude](https://claude.ai) ja kirjaudu sisään.
3. Valitse **Customize → Skills → + → Create skill → Upload a skill**.
4. Valitse lataamasi **viikkosuunnittelu.zip** ja kytke lisätty skilli päälle.
5. Aloita uusi keskustelu ja lähetä tämä viesti:

```text
Käytä viikkosuunnittelu-skilliä. Suunnitellaan ensi viikon menot,
ruoat ja treenit. Kysy tarvittavat tiedot vähän kerrallaan.
```

Vastaa Clauden kysymyksiin. Saat ehdotuksen viikon aikatauluksi ja voit pyytää siihen muutoksia. Voit aloittaa ilman kalenteriyhteyttä ja kertoa sovitut menot itse. Kalenteriin tallentaminen edellyttää yhdistettyä kalenteria ja hyväksyntääsi.

**Skills ei näy?** Ota **Settings → Capabilities → Code execution and file creation** käyttöön ja yritä uudelleen. [Clauden oma ohje](https://support.claude.com/en/articles/12512180-use-skills-in-claude).
